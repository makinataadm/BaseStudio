# Base Studio

Automação de rádio para Windows 10/11 de 64 bits, desenvolvida por César Makinata.

Este repositório distribui somente os instaladores oficiais e os arquivos de atualização. O código-fonte e os dados dos usuários não são publicados aqui.

## Baixar e instalar

Abra a [versão mais recente](https://github.com/makinataadm/BaseStudio/releases/latest), baixe o arquivo Base-Studio-VERSAO-Instalador.exe e siga as instruções do instalador. Consulte o LEIA-ME da versão para ativação, assinatura, funcionamento offline e ajuda.

A partir da versão 1.1.1, o aplicativo verifica novas versões pela internet, baixa em segundo plano e instala quando você encerra normalmente o Base Studio, preservando seus dados. Versões anteriores precisam dessa instalação inicial.

Teste completo de 7 dias. Após o teste, assinatura de R$ 14,99/mês, conforme as condições informadas no aplicativo.
